# maimaiDX 技术验证摘要

本页仅公开可复核的方法、实际结果和限制。内部开发报告、求职草稿及逐次运行证据不随仓库发布；不包含本地私人路径、备份位置、运行进程或凭证。本页未新增测试执行，以下为已完成验证的摘要。

## 成绩精度与历史语义

- 达成率使用 BigDecimal，范围 [0,101]、最多四位小数；数据库目标类型 DECIMAL(7,4)。合法两位、三位输入可规范为四位，超过精度明确拒绝，不在保存前四舍五入至两位。
- 原始达成率和 RA 计算输入一致；RA 计算使用的达成率上限与原始存储分离。旧数据升级仅补零，不从历史 RA 反推已经丢失的小数位。
- 同批次重复谱面的输入记录保留；最佳成绩与 B50 先按谱面身份选择最佳记录，再排序/限量，而非先 LIMIT 50 再去重。成长分析使用一致的最佳选择语义。
- 输入缺少实际游玩时间或事件身份时，只能称保存传入成绩记录，不能将重复上传或 created_at 冒充真实逐次游玩历史。
- 安全迁移脚本为 `database/score_precision_migration.sql`。执行前仍须核实目标库、备份和字段状态；MySQL DDL 不保证整体事务回滚。
- 当前规则并非经完整国服版本锁定的官方 Rating 复刻；曲目类型、新旧曲分组及版本特殊规则的限制不能忽略。

完整回归实际执行 **186 次，成功186、失败0、错误0、跳过0**。另行执行的 MQ 专项9次是完整回归的子集，不相加宣传为独立用例。执行次数不等于测试方法数或代码覆盖率；本结果不包含付费模型评测。

执行器通过独立 Compose 项目、随机端口、专用数据库和运行标识防护隔离开发数据；正常回归不读取项目 .env，不调用外部模型。

`--keep-test-volumes` 保留本次测试卷；默认清理行为及具体前置要求应先查看脚本帮助。运行会生成本地 `docs/validation-evidence/`，该机器的原始证据不公开。测试源码和固定合成题集仍在仓库，保留复测能力。

## Redis 本地轻量性能对比

相同本机、相同 JAR、相同 `GET /api/charts/s001`、相同30首歌曲/90谱面数据；目标返回3个谱面。每种模式预热100次，10/50并发各30秒。MySQL模式关闭缓存代理，Redis模式先回填并确认 Key，再预热与正式测量。

环境：macOS ARM64、Apple M5、16GB、JDK17、Boot3.2.5；MySQL8.0.46与Redis7.4.10运行于本机 Docker。负载客户端与服务共享资源。每种模式仅一轮，不能据此声称统计显著性或生产容量。

## 固定25题真实 LLM 评测

模型为阿里云百炼 OpenAI 兼容接口 `qwen-plus`，仅固定合成问题与工具 Schema；最终回答仍由后端确定性生成，不向模型发送真实成绩或用户身份。评测驱动需显式授权开启，不包含在普通回归中。

题集：`backend/src/test/resources/llm-evaluation-cases.json`。真实请求25次，其中24次产生 LLM 规划、1次规则降级。纯 LLM 工具匹配24/25、参数匹配23/25；最终含降级链路工具匹配25/25、参数匹配24/25。合法业务题22/22执行成功；非法请求安全处理2/3，整体正确处理24/25。

必须区分“模型输出”“含降级的最终结果”和“业务执行”；**不能把含规则降级的25/25工具匹配称为模型或生产准确率100%**。固定题集规模小、未锁定模型具体版本、无重复采样，不外推为通用准确率。一个 JUnit 评测驱动通过也不表示25题全对。

历史题集将逆序区间判为非法；后续产品约定允许规范化上下界，但没有追改历史结果或补算分数。规则 Planner 与 Tool 尚未统一此解释，属于已知限制。
